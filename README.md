# Studio Paint AS

App Android de desenho profissional (pintura raster), irmão do **Animation Studio**
(`layouter787-source/Animation-Studio-`). Os dois apps trocam projetos através do formato
aberto **ASPK** (`.aspk`), descrito em [`docs/INTERCHANGE.md`](docs/INTERCHANGE.md).

> Estado honesto: este repositório contém a fundação real e compilável do app. Nada aqui é
> marcado como concluído sem estar implementado e testado. Veja [`docs/ROADMAP.md`](docs/ROADMAP.md).
